# CarWorld changelog

This changelog preserves the release history recorded by the original
SourceForge project. Dates and descriptions retain the meaning of the
historical project documentation.

## 0.245 — 16 December 2009

- Fixed the dark truck rendering bug.
- Fixed white textures on first launch.
- Fixed a crash on exit.

The preserved SourceForge package was published as `0.245.1`.

## 0.244

- Replaced the custom image loader with SDL_image.
- Replaced PPM textures with PNG images.
- Updated the Visual Studio project.
- Used SDL OpenGL extension querying and removed most `WIN32` conditionals.

## 0.243 — 28 June 2006

- Added GCC 4.1 compatibility.
- Removed Visual Studio .NET 2005 compilation warnings.

## 0.241 — 9 June 2006

- Added GCC 4.0.4 and Visual Studio .NET 2005 compatibility.
- Fixed NUL characters being written to the Windows configuration file.

## 0.239 — 7 April 2004

- Ported CarWorld to SDL and removed most platform-specific code.
- Supported GCC 3.3.1 and Microsoft Visual C++ 6.0.
- Known limitations included Linux configuration-file handling and server mode.

## 0.223 — 20 September 2000

- Enabled networked mode under Windows.

## 0.222 — 19 July 2000

- Straightened the truck.
- Added an RPM package target to the Makefile.

## 0.219 — 15 June 2000

- Added DirectInput force-feedback support.
- Removed the GLU dependency used at that time.
- Added automatic restart.
- Fixed the initial vehicle balance.

## 0.215 — 19 April 2000

- Improved networking.
- Added the first BeOS build.
- Applied contributed patches.

## 0.205

- Added preliminary network-game support for Unix and Linux.

## 0.198

- Fixed bugs and added Linux joystick support.

## 0.190

- First release.

## Repository migration — 26 July 2026

- Imported the SourceForge SVN history into Git.
- Moved project development to GitHub.
- Preserved the historical project website with GitHub Pages.
- Restored available SourceForge packages as GitHub Releases.
